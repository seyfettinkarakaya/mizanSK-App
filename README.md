# MizanSK uygulaması (arayüz kabuğu)

Bu depo yalnız telefon uygulamasının arayüz kodunu yayımlar (GitHub Pages). **Veri, anahtar ve adres içermez.** Kullanıcı kendi Apps Script adresini ve anahtarını ilk açılışta girer; ikisi cihazda şifreli kalır, ağdan geçmez.

Dosyalar: `index.html`, `app.js`, `crypto.js`, `style.css`, `sw.js` (yalnız kabuğu önbelleğe alır, API yanıtını asla), `manifest.webmanifest`, `icon*`.

Bu depoya kişisel veri, anahtar ya da adres konmaz.
